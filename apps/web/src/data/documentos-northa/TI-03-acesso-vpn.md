# Acesso VPN — Northa Soluções Logísticas

## Elegibilidade
O acesso VPN é liberado automaticamente para colaboradores em **home office aprovado**
pelo gestor (ver política RH-03).

## Instalação
O cliente VPN utilizado é o **GlobalProtect**. A instalação é feita via portal de TI
(portal.northa.com/ti > "Acesso Remoto"), com tutorial em vídeo disponível na base de
conhecimento interna.

## Problemas de Conexão
Se a VPN não conectar:
1. Verifique se o cliente GlobalProtect está atualizado;
2. Confirme que a senha corporativa está válida (ver TI-02);
3. Se o problema persistir, abra chamado categoria "Acesso Remoto".

## Segurança
É proibido compartilhar credenciais de VPN com terceiros. O uso da VPN é monitorado e
auditado conforme a Política de Segurança da Informação.
